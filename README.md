# rcc

A Rust compiler written in C, built for one job: compiling
[ccc](https://github.com/anthropics/claudes-c-compiler), a C compiler written in
Rust. `rcc` turns ccc's Rust into C, and ccc can compile `rcc`'s own C, so the
two tools can build each other without rustc or gcc. It was developed against a
ccc checkout that has arm64 macOS support.

`rcc` is not a general Rust compiler. It accepts known-good code only: there is
no borrow checker, lifetimes are ignored, diagnostics are minimal, and it
supports the language features and standard-library APIs that ccc uses.

## How it works

```
Rust source -> lex -> parse -> macro expansion -> name resolution
            -> type check (inference + traits) -> monomorphization
            -> MIR with drop elaboration -> C source -> C compiler
```

- `src/` — the compiler, about 30k lines of C11 using only libc.
- `lib/std/` — our own standard library in plain Rust (about 25k lines),
  compiled from source with every program. The real libstd is not used.
- `rt/` — the C runtime linked into every output program.
- `tests/run/` — 333 Rust programs with expected output generated by rustc 1.88.
- `demo/` — the bootstrap chain and the acceptance demo.
- `DESIGN.md`, `docs/ARCHITECTURE.md`, `docs/STATUS.md`, `docs/INVENTORY.md` —
  design contract, internals, current state, and the inventory of what ccc needs.

## Build and test

```sh
make                                  # builds build/rcc with the system C compiler
RCC_CC=clang tests/run.sh             # runs the Rust test corpus
build/rcc hello.rs -o hello           # C compiler taken from $RCC_CC (default cc)
```

Scripts that need a ccc checkout look for it at `~/dev/ccc`; set `CCC_DIR`
(demo) or `CCC_SRC` (tests) to point elsewhere.

## The bootstrap demo

```sh
cd demo
make chain      # rustc-built ccc -> rcc built by ccc -> ccc built by rcc -> again
make bench      # ocean.c compiled by each ccc and by clang; same checksum required
make difftest   # ccc's own differential suite with the rcc-built ccc
make selftest   # the Rust corpus through the bootstrapped toolchain only
```

See `demo/README.md` for what each stage proves and for measured numbers.

## Status and limitations

- Developed and tested on arm64 macOS only. There, ccc still uses the system
  assembler and linker, so a fully clang-free chain needs Linux, which is untested.
- The rcc-built ccc is judged by behaviour, not byte-identical output: ccc's
  code generation depends on hash-map iteration order.
- Closing the loop currently requires skipping one ccc peephole pass that
  miscompiles the generated C; see `docs/STATUS.md` and `tests/core/ccc_bugs/`.
- Panics do not unwind. A panic on a spawned thread is caught at `join()`
  without running destructors.

Parts of the test corpus are adapted from ccc, which is released under CC0.
